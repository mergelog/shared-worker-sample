SharedWorkerの4つのデモ
01state

状態共有

Workerが持つカウンターを、すべてのタブに反映。連打してもWorkerが順番に加算します。

{{ shared.snapshot().counter }}

試す: 片方のタブで加算 → もう片方も同じ値に。

02websocket

WebSocket共有

接続を持つのはWorkerだけ。どのタブから送っても、サーバーの応答を全タブが受け取ります。

{{ shared.snapshot().socketStatus }}
@for (message of shared.socketMessages(); track $index) {
{{ message.text }} 接続ID: {{ message.connectionId }} / サーバー全体の接続数: {{ message.activeConnections }} / {{ message.timestamp | date:'HH:mm:ss' }}
} @empty {

接続すると、5秒ごとの時刻と送信したメッセージが届きます。

}

試す: 両タブから接続 → 接続IDが同じ、接続数は1。

03cache

データキャッシュ

APIの結果をWorkerのメモリに30秒間保存。同時に取得してもAPIリクエストは1回です。

@if (shared.snapshot().cacheLoading) {

APIから取得中…

} @if (shared.snapshot().cache; as data) {

{{ data.message }}

APIリクエスト番号
{{ data.requestId }}
取得時刻
{{ data.fetchedAt | date:'HH:mm:ss' }}
} @else if (!shared.snapshot().cacheLoading) {

まだデータがありません。

} {{ shared.cacheSource() }}

試す: 別タブで続けて取得 → 番号が変わらず、取得元がcacheに。

04message

タブ間通信

操作をほかのタブへ通知。通知は保存せず、その時点で接続しているタブだけに届けます。

{{ sentNotification() }}

@for (notification of shared.notifications(); track $index) {
{{ notification.text }} 送信元: {{ notification.from }} / {{ notification.timestamp | date:'HH:mm:ss' }}
} @empty {

ほかのタブからの通知がここに届きます。

}

試す: タブAで通知 → タブBだけに表示。後から開くタブには届きません。

Angular → MessagePort → SharedWorker → MessagePort → Angular

共有できるのは、同じブラウザープロファイル・同じオリジン（スキーム、ホスト、ポート）のタブです。
全タブを閉じてWorkerが終了すると、状態とキャッシュは失われます。詳しくはREADMEへ。
